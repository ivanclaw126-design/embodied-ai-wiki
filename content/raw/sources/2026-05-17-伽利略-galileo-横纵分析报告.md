## 摘要

伽利略不是“同名机器人概念”的泛称，本轮可核验的主体应落在 **伽利略（天津）技术有限公司**。公司官网元信息、世界机器人大会展商页、BOSS 直聘工商信息和建设通工商信息均指向同一主体；其中 BOSS 与建设通给出统一社会信用代码 `91120112MA07FH4P1R`，法人杨凯，成立日期 2021-10-11，注册地址在天津市津南区双港镇双港高科技产业园。

一句话结论：**伽利略应纳入“国内具身智能本体公司”观察池，但更准确的定位不是通用人形机器人公司，而是从轨道交通、电力、安防、应急等特种场景长出来的四足/轮足本体公司；人形方向存在产品与研发口径，但官方可核验强度明显低于四足产品。**

这家公司最有价值的地方，在于它不像很多人形机器人创业公司从实验室 demo 走向场景，而是从系统集成、数字孪生、雷达、无人机、智能运维和特种巡检需求里反向长出机器人本体。天津政务网在 2026-02-02 报道称，伽利略 2021 年将总部从北京迁到天津，北京保留部分研发功能，并借助天津高校和制造业资源提升机器狗运动能力与灵活性，报道还给出“产品国内市场占有率达到 40%”的说法。这个口径来自政府新闻转载的天津日报，属于较高参考价值但仍需在尽调中要求公司提供统计口径。

最大风险也在这里：伽利略的公开信息强烈依赖展会页、招聘页、地方媒体和营销稿。官网本身是 SPA，公开 API 能确认“具身机器人系列”下 C1、C1-W、E1、E1-W、S1 等产品，世界机器人大会展商页还能确认 E1、C1 和 S1-E 防爆四足系列；但本轮未在官网公开产品 API、官网前端资源、世界机器人大会展品页中检索到 GH1 人形产品。人形机器人 GH1 的参数主要来自机器人世界等第三方平台，津云/搜狐采访中则是“推进第二代人形机器人研发”。因此，报告将四足/轮足作为高置信主线，人形作为低到中低置信补充线。

## 研究口径

本报告把“伽利略”拆成三层处理。

第一层是主体核验：优先确认是否存在明确工商主体、官网、产品页、展会官方页和可追溯经营信息，避免把傅利叶智能的“伽利略运动评估系统”、欧盟 Galileo 卫星导航系统、深圳市伽利略机器人有限公司、教育/导航软件协议文档等同名对象误配到本轮公司名单。

第二层是本体口径：只把可验证的机器人整机纳入核心分析。官网元信息写有“机器人、智能仿生机器人、四足机器人、软件系统、雷达、无人机”；官网公开 API 将产品分类为“具身机器人系列、雷达系列、配件”，其中具身机器人系列可见 C1、C1-W、E1、E1-W、S1。世界机器人大会展商页进一步确认智能仿生机器人系列是五大产品线之一，并给出 E1、C1、S1-E 防爆四足系列及水文、警用安防、国网办公室巡检、应急安防等场景案例。

第三层是一级市场口径：公开融资报道缺失，BOSS 直聘页面标注“未融资”，但世界机器人大会英文展商页和中文展商页均称其为“国有投资企业”；BOSS 页面又称北京理工大学已成为重要股东。由于未取得股权穿透表，本报告不把它写成典型 VC 融资公司，而写作“国有/高校/地方产业资源色彩较强、融资轮次未公开”的本体企业。

## 纵向发展

### 1. 北京研发源头与天津承接：不是单点机器人创业，而是京津冀转化样本

伽利略公开叙事的起点有两个版本。工商层面，伽利略（天津）技术有限公司成立于 2021-10-11；媒体叙事层面，地方报道称企业“成立于北京”，2021 年将总部从北京迁到天津，北京保留部分研发功能。天津政务网转载天津日报的报道把伽利略放在京津“双城记”的语境里，强调它利用天津高校资源和制造业优势完成产品升级。

这解释了伽利略与很多机器人公司的差异。它不像宇树那样先以高性价比四足硬件打开全球开发者和消费级市场，也不像众擎、星动纪元那样把人形本体作为品牌叙事中心。伽利略更像是一家从工程项目、智能运维、雷达感知和特种巡检里长出来的机器人公司。官网元信息和天津商业大学就业信息网都把它的产品组合写得很宽：数字孪生智能综合运维平台、智能硬件、毫米波雷达/雷视融合、机器人、无人机、卫星通信。

这个宽产品面既是优势，也是包袱。优势是它更容易切进电力、轨交、应急、军警安防等复杂采购场景；包袱是市场在给具身智能公司估值时，往往更偏好一个干净的本体/模型故事，而伽利略需要证明这些系统工程能力能沉淀成可复用的机器人平台，而不是项目制交付。

### 2. 2023-2024：资质、标准与特种四足场景的早期沉淀

公开资质信息显示，伽利略在 2023 年取得 CS1 信息系统建设和服务能力评估证书。2024 年，伽利略参与了 `T/ZSRA 003-2024 特种四足机器人本体通用技术要求` 起草，起草单位还包括中关村融智特种机器人产业联盟、云深处、公安部第一研究所、应急管理部上海消防研究所、智元、优宝特、七腾等。

这个标准线索很重要。它把伽利略放进“特种四足机器人”而不是泛服务机器人或娱乐机器狗的行业坐标里。标准适用范围写的是军警、应急、特殊民用，如电力、石油、石化、矿业等领域，不适用于消费、娱乐四足机器人。伽利略与七腾、云深处、优宝特同列起草单位，说明它至少已进入特种四足机器人行业规则讨论圈。

对一级市场判断而言，标准参与本身不等于技术领先，但它说明伽利略面对的是采购门槛高、认证要求高、场景复杂度高的市场。这类市场的客户不会只看机器狗会不会翻跟头，而会看防爆、防护等级、续航、负载、通讯、远程接管、设备挂载、平台接入和售后响应。伽利略公开材料反复强调的“数字孪生平台 + 雷达 + 无人机 + 机器人”组合，正适配这类场景。

### 3. 2025：天开津南园叙事与行业应用展示

2025 年，天津网信网转载天津日报的天开园报道，将伽利略列为津南园代表企业之一，称其基于数字孪生技术的智能化软件，通过自主研发核心技术，涉及卫通设备、无人机、雷达等产品研发与销售，并已逐步实现从研发到生产的全产业链运营。

同年 9 月，展会库转载“伽利略Galileo”消息，称伽利略（天津）技术有限公司携自主研发智能仿生四足机器人亮相 2025 天津国际工业自动化及机器人展。艾邦机器人也报道其在智慧轨道交通大会上推出全栈自研智能仿生四足机器人，并称其为轨道交通行业四足机器人巡检运维供应商。上述来源带有企业传播色彩，证据等级低于政府/展会官方页，但与天津网信网、WRC 展商页、官网 API 可相互印证四足机器人主线。

这一阶段，伽利略的真正方向已经清楚：它不是为了“通用机器人”去找场景，而是先拿轨交、电力、水利、安防、应急这些明确场景，再把机器人作为移动载体嵌进去。它卖的不是单台机器狗，而是“机器狗 + 感知载荷 + 远程控制 + 行业平台 + 运维服务”的工程包。

### 4. 2026：产品公开化、赛事曝光与人形叙事增强

2026 年 2 月，官网公开 API 显示“具身机器人系列”下有 C1、C1-W、E1、E1-W、S1 等产品，商品链接指向京东。这是本轮最直接的官方产品证据。世界机器人大会 C1 产品页则把 C1 描述为兼具消费级与工业级应用特性的高性能四足机器人，支持全天候作业、超长续航、定制搭载全景摄像头和有毒有害气体传感器，核心能力包括自主充电、全场景覆盖、较高负载自重比和复杂地形运动控制。WRC E1 和 S1-E 页面进一步把 E1 定义为面向行业应用高层级需求的四足产品，把 S1-E 定义为工业高危复杂环境的防爆四足系列。

同年 4 月，伽利略在 2026 机器人勇士挑战赛中获得更强曝光。天津日报/新浪转载报道称，天开津南园企业伽利略携自研四足机器人“铁甲天狼队”和轮足复合机器人“铁甲天龙队”参赛，包揽四足机器人组别、轮足复合机器人组别全国冠军，并获得极速奖、通关奖。赛事场景强调应急救援、17 项障碍关卡、运动控制、全地形越障与复杂环境适应能力。这个节点强化了伽利略的“特种足式机器人”定位。

人形方向也在 2026 年显著出现。机器人世界在 2026-04-12 发布 GH1 具身智能人形机器人页面，给出 155cm、45kg、31 自由度、4m/s、自研高扭矩密度关节电机等参数。津云/搜狐 2026-02-25 采访则称杨凯表示公司将推进第二代人形机器人研发，重点突破端到端敏捷移动与生成式自主运动技术。二者共同说明伽利略有人形方向线索，但证据强弱不一样：GH1 参数页不是公司官网，本轮也未在官网产品 API、官网前端资源或 WRC 展品页中找到 GH1；采访是研发规划而非量产产品公告。因此，本报告不把伽利略的人形产品与宇树 H1/G1、傅利叶 GR 系列、众擎 PM/SE/T 系列放在同一置信等级上。

伽利略的技术叙事可以概括为三句话。

第一，它把本体运动控制放在特种场景里验证。四足、轮足、防爆和巡检能力比“通用陪伴”更重要。

第二，它把机器人当成移动感知平台。红外热像仪、气体传感器、全景摄像头、雷达、北斗/GPS/RTK、机械臂、破拆设备等载荷，才是客户采购时的真实问题。

第三，它试图把硬件与行业平台绑定。国网数字科技办公室巡检案例中，WRC 页面强调未带工牌识别、跨楼层巡检、自主充电和全天候巡检，说明伽利略的价值不只在“走”，还在“看、识别、报警、回传、接入系统”。

## 横向对比

### 与宇树科技：伽利略像“特种工程派”，宇树像“平台硬件派”

宇树科技的优势在于产品谱系极宽、价格带清晰、全球开发者认知强。宇树官网已有 Go2、B2、H1、G1 等成熟产品页，其中 H1 被官网定义为全尺寸通用人形机器人，Go2 则是典型四足机器狗产品。宇树的品牌势能来自高频公开演示、规模化出货、开发者生态和极高传播效率。

伽利略与宇树的竞争不是完全正面。伽利略不太可能在消费级机器狗和开发者社区里与宇树拼性价比，它更像是在电力、轨交、石化、应急、安防等客户里拼方案完整度。对客户来说，宇树是一台可以买回来二次开发的高性能平台；伽利略则希望成为一整套无人化巡检系统的承包方。

伽利略的机会在于：行业场景里，硬件价格不是唯一变量，防爆、防护、载荷、集成、资质、驻场和售后都可能成为中标条件。伽利略的风险在于：如果宇树、云深处、七腾等也强化行业方案能力，伽利略的“系统集成”优势会被压缩，最终仍要回到本体可靠性、成本和量产一致性。

### 与云深处：同在四足/特种巡检，但云深处的本体品牌更集中

云深处是中国四足机器人代表公司之一，长期聚焦“绝影”系列四足机器人，并在 2024 年发布人形机器人 Dr.01。与云深处相比，伽利略的公开产品叙事更分散：机器人、雷达、无人机、卫星通信、数字孪生平台同时出现。

这种分散并非一定是坏事。特种巡检客户往往不是只要机器狗本体，而是要数据采集、远程监测、平台回传和应急联动。但在一级市场表达上，云深处更容易被理解为“足式机器人公司”，伽利略则需要更多解释：它到底是本体公司、系统集成商、智能运维平台公司，还是低空经济/雷达/卫星通信综合公司？

我对伽利略的判断是：它不应被拿来和云深处做单纯参数表对比，而应看“行业项目复用率”。如果伽利略能把轨交、电力、石化、应急四个行业的方案做成标准化模块，它的宽产品线就有协同；如果每个项目都要重新定制，它的规模化价值会大打折扣。

### 与七腾机器人：都切特种场景，但七腾更像防爆巡检老兵

七腾机器人在防爆巡检、石油石化和工业特种机器人领域积累更早，公开材料中防爆证书、行业案例、工业客户关系更容易被识别。伽利略也在公开材料中强调防爆足式机器人和工业特种机器人市场，但本轮仍缺少公司官网级的防爆产品页、证书编号和项目合同证据。

伽利略相对七腾的差异是，它把四足/轮足和人形、雷达、无人机、卫星通信、数字孪生平台放在同一套智能运维叙事里。这个叙事更“具身智能”，也更适合未来电网、轨交、园区等综合场景。但在尽调中，必须把概念拆开问：哪些能力已经产品化？哪些只是展会演示？哪些由合作伙伴提供？哪些是项目制软件？

### 与众擎、五八、傅利叶等人形本体公司：伽利略的人形仍处在“补线”而非“主线”

众擎、五八、傅利叶这类公司的人形产品线更明确，品牌传播也更围绕人形机器人展开。伽利略公开材料中的人形线索有两类：第三方产品页中的 GH1 参数，以及地方采访里“推进第二代人形机器人研发”的规划。

这两类证据还不足以证明伽利略是人形赛道头部公司。它更像是在四足/轮足巡检的技术栈上向人形延伸：先做足式运动、复杂地形、场景感知，再补双臂、人形、生成式自主运动。这个路线有现实性，但短期商业化重心仍应看四足/轮足特种场景。

如果未来伽利略能在电力、石化、轨交等场景里证明“人形 + 四足/轮足 + 平台”的多机器人协同，它会有区别于纯人形公司的生态位。否则，人形只是品牌叙事上的加分项，不能作为估值主逻辑。

## 横纵交汇洞察

伽利略的历史路径决定了它今天的竞争位置。

它不是从“我要做通用机器人”这个宏大命题出发，而是从“客户在高危、复杂、非结构化场景里需要少人化、无人化作业”出发。这个起点让它天然重视防爆、巡检、感知、通讯、平台和交付，而不是只重视运动控制演示。因此，它的四足机器人看起来没有宇树那么强的消费级传播势能，却更容易进入电力、轨交、石化、应急这些预算明确、痛点明确、认证明确的场景。

但同一条路径也埋下了限制。系统集成公司最容易陷入“每个客户都不同”的泥潭。伽利略要从项目公司变成本体公司，需要证明三件事：一是核心本体平台可规模复制；二是行业载荷和软件平台可模块化；三是售后运维网络能支撑跨省交付。天津政务网和津云/搜狐采访中提到全国 26 个省份覆盖、工业特种机器人市场占有率、100 多台足式机器人交付、55 亩产业基地和 2027 年投产预期，这些都指向规模化叙事，但都需要合同、产能、出货、收入和毛利率验证。

横向看，伽利略的最佳生态位不是“下一个宇树”，而是“特种场景具身智能承包商”。它可以把本体、雷达、无人机、卫星通信和数字孪生平台组合起来，吃掉电力/轨交/石化/应急客户中最难标准化但最有预算的部分。这个位置的护城河不只在机器人算法，而在行业 know-how、资质、交付案例、地方资源和供应链。

未来三种剧本：

- 最可能剧本：伽利略继续以四足/轮足巡检为主线，在电力、轨交、安防、应急里扩张，成为区域和行业型特种机器人公司，人形作为展示和中长期研发线保留。
- 最危险剧本：宇树、云深处、七腾等本体能力更强的公司向行业方案下沉，伽利略如果缺少可验证的本体成本/性能优势，就会被压成项目制系统集成商。
- 最乐观剧本：伽利略依托天津产业基地和高校/地方资源，把四足、轮足、人形、无人机、雷达、卫星通信做成多机器人协同平台，在电网、石化和轨交形成标杆订单，进而具备科创板申报条件。

6. 请公司说明“市场占有率 40%”的统计口径，是工业特种四足、足式机器人、防爆足式、天津区域，还是其他更窄市场。

7. 请公司说明人形机器人路线：GH1 是否为公司官方产品，第二代人形机器人预计发布时间、目标场景、核心关节/控制/感知/大模型能力是否自研。

8. 请公司说明与北京理工大学、西北工业大学、西安电子科技大学、天津大学、南开大学、中国民航大学的合作协议状态、投入资源、知识产权归属和成果转化安排。

9. 请公司说明京东/阿里巴巴等电商渠道实际成交量，区分展示型 SKU 与真实销售 SKU。

10. 如公司计划科创板申报，请提供收入规模、研发费用率、专利清单、核心技术人员稳定性和历史股权合规情况。

## 结论

伽利略可以纳入本轮具身智能本体公司名单，但应该采用谨慎口径：**“特种场景四足/轮足本体公司，正在向人形和多机器人协同延伸”**。它的高置信价值来自四足/轮足机器人在电力、轨交、安防、应急等行业的落地线索，以及天津产业转化、标准参与和工程交付资源；它的低置信部分是人形机器人商业化、融资股权结构、客户订单规模和互联网/国际高校合作。

如果只看“人形机器人热度”，伽利略不是最干净的标的。如果看“具身智能在高危复杂场景中率先落地”，伽利略值得继续尽调。
