# 女娲机器人横纵分析报告

生成日期：2026-05-18  
研究对象：女娲机器人  
名单编号：#130  
名单状态：冲突：纳入 vs 观察  
输出范围：只生成 Markdown 报告，不生成 PDF，不导入 wiki。  
研究方法：按 hv-analysis 横纵分析法组织，重点核验主体、同名混淆、融资历史、团队来源、产品能力、客户/订单、产业合作与建议名单口径。

> 一句话结论：#130 的“女娲机器人”不宜按“具身智能本体公司”直接纳入。可核到的中国大陆主体更像 **深圳市女娲机器人科技有限公司 / evarobot**，公开商业化主线是家庭小型人形机器人和商用清洁服务机器人；2019 年完成 Pre-A 轮后，未检索到 2020-2026 年新增融资、量产人形本体、具身大模型、灵巧操作、核心部件或当前活跃客户订单的一手证据。另有 **NUWA Robotics（台湾女媧創造）** 和 **Nuwax Agent OS（成都第二空间智能科技有限公司）** 与“女娲/NUWA/Nuwax”同名近似，但不应并入本条主体。

## 摘要

这次研究最重要的工作不是把“女娲机器人”写成一家机器人公司，而是先把三个名字拆开。

第一条线是 **深圳市女娲机器人科技有限公司**。英诺嘿呀企业页显示该公司成立于 2017-05-09，法定代表人金银玉，融资次数 1 次，行业标签包含服务机器人/商用服务机器人/市政工程机器人，融资页记录 2019-12-24 完成 Pre-A 轮、金额为“CNY 千万级”、投资方为南山创投、朗科投资、青赢创投。[S1] 36氪项目库也记录公司官网为 `http://www.evarobot.com.cn`，工商全称为深圳市女娲机器人科技有限公司，并将 2019-12 Pre-A 金额写作“千万级人民币”。[S14] 私募股权投资网记录同一融资事件，投资时间为 2019-12-24，投资金额写为“RMB数千万”，投资方同为南山创投、朗科投资、青赢创投。[S2] 投资界/清科 2019-12-25 报道则称女娲机器人完成千万级 Pre-A 轮融资，由南山创赛基金领投，朗科投资、青赢创投跟投。[S3]

第二条线是 **深圳市天益智网科技有限公司 / 小天智能人形机器人**。深圳市机器人协会 2017 年机器人博览会材料显示，天益智网展示“小天智能人形机器人”，该产品是基于 Android 系统的小型人形双足机器人，支持早教、通话、视频、智能家居控制、家庭防护等功能；同一材料还称天益智能机器人包括智能小型/大型/巨型人形机器人及扫地、巡逻、巡检等特种服务机器人。[S4] 这条线能解释女娲机器人早期为什么会被一些清单归入“人形本体”，但公开证据更接近 2016-2017 年服务/教育机器人和小型家庭机器人，不能直接外推为 2024-2026 年意义上的具身智能本体公司。

第三条线是 **Nuwax Agent OS / 成都第二空间智能科技有限公司**。Nuwax 官网与西南财经大学自然语言处理团队 2026 年 1 月文章显示，Nuwax 是“女娲智能体操作系统 / 女娲智能体OS”，由成都第二空间智能科技有限公司开发，核心是智能体系统、工作流、工具调用和多模态交互；官网介绍说其智能体可迁移到桌面机器人、人形机器人和机器狗等多种载体。[S5][S6][S7] 这是一条具身 OS/智能体平台线索，但法律主体、团队、产品和融资均与深圳女娲机器人不同。若名单目标是 Nuwax，应另建“成都第二空间 / Nuwax Agent OS”条目，不能把它并入 #130。

我的判断：#130 应从“人形本体/智能体OS”冲突项改为 **观察池：历史服务机器人/商用清洁机器人；同名 Nuwax Agent OS 另行观察**。如果本库只收“具身智能本体/核心部件/具身大脑”，深圳女娲机器人当前证据不足以纳入；如果本库保留更宽的“服务机器人观察池”，可保留，但必须标注“2019 后活跃度和当前业务待核验”。

## 纵向分析

### 1. 2016-2017：从“小天”家庭小型人形机器人说起

女娲机器人被误放进“人形本体”名单，最早可能来自天益智网的“小天智能人形机器人”。

2017 年深圳机器人博览会材料中，天益智网展示的小天机器人被描述为“远程全能保姆家居智能机器人”，核心功能包括早教、通话、视频、智能家居控制和家庭防护。更关键的是产品形态：它是基于 Android 4.2 系统的小型人形双足机器人，支持 APP 安装、手机/PC 编辑舞蹈动作、GSM/WCDMA SIM 卡远程通话和视频功能。[S4]

这不是今天意义上的通用人形本体。它更像 2015-2017 年家庭服务机器人热潮里的“小型人形交互终端”：有双足外形，有 Android，有语音和视频，有家庭场景，但不具备公开可验证的通用操作、灵巧手、VLA 模型、复杂运动控制或工业落地能力。

source/date/entity/evidence_level：深圳市机器人协会 / 2017-04 前后 / 深圳市天益智网科技有限公司、小天智能人形机器人 / L1-L2。

### 2. 2017-2018：深圳女娲机器人公司化，开始转向商用服务机器人

英诺嘿呀显示深圳市女娲机器人科技有限公司成立于 2017-05-09。[S1] 36氪项目库将万文惠列为创始人，并写其为深圳市天益智网科技有限公司创始人；铅笔道也写万文惠为女娲机器人创始人、天益智网创始人兼董事长。[S10][S14] 这能支持“天益智网-女娲机器人”存在重要历史关联，但仍不能替代工商穿透。

铅笔道 2019 年报道给出另一组创始人/团队口径：万文惠为女娲机器人创始人、天益智网创始人兼董事长，拥有十多项专利技术并带领超过 30 人研发技术团队；正文还称公司位于深圳南山智园，研发团队 50 余人，由北京大学刘宏博士、香港科技大学蒋仕龙博士带领。[S10] 这些信息能强化“天益智网-女娲科技”的历史联系和清洁机器人研发团队线索，但与工商高管口径、投资界报道的人物履历存在差异，需放入待复核事项。

这段历史说明，女娲机器人从“小天”式家庭机器人转向了更现实的商用服务机器人。家庭小型人形机器人对成本、续航、交互、售后和用户粘性要求很高，2016-2017 年大量公司在这条路上遇到天花板；商场、校园、医院、景区和保洁场景至少有更明确的 B 端预算和运营流程。

source/date/entity/evidence_level：英诺嘿呀 / 2026-05-18 / 深圳市女娲机器人科技有限公司 / L3；投资界 / 2019-12-25 / 女娲机器人 / L2；铅笔道 / 2019-12-25 / 女娲科技、万文惠 / L2-L3。

### 3. 2019：清洁服务机器人成为核心可见产品

铅笔道 2019 年报道称，女娲科技推出两款产品：户外清扫机器人“大扫”和室内清扫机器人“小扫”，核心功能包括自主规划、智能清扫、实时监控、APP 管理和大数据，可应用于工业园区、校园、景区、室外广场、机场大厅等半封闭环境；报道还称机器人采用扫、吸和无人驾驶模式，支持深度学习建图、自主规划分区清扫、自适应吸力控制、自动回充和 APP 监控，单次清扫面积约 1000 平米/小时，充电一次覆盖约 4000 平米。[S10]

这里已经能看到女娲机器人的产品真实位置：它不是当前人形本体公司，而是商用清洁服务机器人公司。大扫/小扫属于机器人应用层产品，强调低速无人驾驶、导航、清扫和运维管理，但和“具身智能本体”名单里宇树、智元、乐聚、星动纪元、银河通用等人形/通用机器人公司不是一个赛道。

source/date/entity/evidence_level：铅笔道 / 2019-12-25 / 女娲科技、大扫、小扫 / L2-L3。

### 4. 2019：Pre-A 融资与机场/园区场景叙事

2019 年 12 月，女娲机器人完成 Pre-A 轮融资。投资界 2019-12-25 报道的金额是“千万级”，投资方口径为“南山创赛基金领投，朗科投资、青赢创投跟投”。[S3] 私募股权投资网记录的投资时间为 2019-12-24，金额为“RMB数千万”，投资方为南山创投、朗科投资、青赢创投。[S2] 英诺嘿呀融资页记录为 2019-12-24 Pre-A 轮，金额“CNY 千万级”，投资方为南山创投、朗科投资、青赢创投；36氪项目库记录为 2019-12 Pre-A 轮、千万级人民币、南山创投/朗科投资/青赢创投。[S1][S14]

同一时期，投资界报道给出产品能力：女娲机器人采用机器人底盘开发技术、自主导航算法、SLAM 地图构建、离散覆盖清扫路径规划、自动充电等技术，并称女娲室内扫吸一体机器人可通过智能硬件和 AI 算法，根据环境和清洁需求自发生成清洁解决方案，实现“感知环境、分析情况、根据情况做出决策”。[S3]

场景方面，投资界报道写到公司室内扫吸一体机器人已在新加坡樟宜机场、北京大兴机场等公共场所投入使用，户外大型清扫机器人已在杭州下城区智慧城市示范园区、深圳大学城、深圳湾公园及深圳少年宫等区域投放运营。[S3] 这是一条有价值的客户/场景线索，但需要克制：来源来自投融资报道，不是客户方公告、采购合同、中标公告或验收报告。因此报告采用“场景投放/应用线索”，不写成已验证客户订单或持续收入。

### 5. 2020-2021：高新资质与司法风险线索

深圳市科技创新局附件《拟资助企业名单》PDF 中可检索到“深圳市女娲机器人科技有限公司”和证书编号 GR201944205604，说明公司曾进入 2019 年国家高新技术企业相关资助名单。[S11] 这能支持“有一定研发资质/高新企业身份”的历史判断，但不能证明当前仍活跃，也不能证明具身智能本体能力。

司法风险方面，企查查公开 PDF 显示，北京市第一中级人民法院在 2021 年 1 月作出执行裁定，执行依据涉及劳动争议，被执行方包括深圳市天益智网科技有限公司、深圳市女娲机器人科技有限公司等，法院裁定冻结、划拨或查封、扣押、冻结、拍卖、变卖被执行人相应财产。[S12] 这不是“公司破产”的直接证据，但对活跃度和经营稳定性是负面线索，尤其是女娲机器人 2019 年后很少出现新产品、新融资和新客户公告时。

source/date/entity/evidence_level：深圳市科技创新局附件 / 2020 前后 / 深圳市女娲机器人科技有限公司 / L1；北京市第一中级人民法院裁定 PDF / 2021-01-20 / 深圳市女娲机器人科技有限公司 / L1。

### 6. 2022-2026：公开活跃度下降，官网失效，同名 Nuwax 出现

英诺嘿呀页面保留了 2022 年左右的“女娲机器人清洁机器人”视频动态，但本轮未检索到 2023-2026 年深圳女娲机器人新增融资、量产升级、客户订单、具身大模型、核心部件或人形机器人新品发布。[S1]

更重要的是，女娲机器人登记/数据库指向的 `evarobot.com.cn` 当前访问时不再呈现机器人公司官网，而是显示股票配资相关站点“久联优配”。这通常意味着旧域名失控、网站被改站或公司不再维护公开官网。对一级市场研究来说，这是一个必须保留的风险项。

2026 年 1 月前后，另一个“女娲”开始出现：Nuwax 女娲智能体 OS。西南财经大学自然语言处理团队文章称 Nuwax 是全球首款智能体 OS，成都第二空间智能科技有限公司成立于 2023 年 10 月，由西南财经大学赵宇教授创办，Nuwax 源于中文“女娲”。Nuwax 官网称其支持智能体构建、工作流、工具调用、多平台交互，并可将 AI 能力迁移到机器人和机器狗等载体。[S5][S6][S7]

这条线值得关注，但它不是深圳女娲机器人的延续。它更接近具身智能软件层/智能体 OS 观察对象，应单独建档。

## 产品能力与技术路线

### 小型人形机器人线

可验证材料主要来自天益智网的小天智能人形机器人：Android 4.2、小型双足、视频通话、家庭防护、教育资源、舞蹈动作编辑。这是家庭陪伴/教育机器人逻辑，和“具身智能本体”里要求的通用操作、全身运动、灵巧手、机器人基础模型不是一回事。

source/date/entity/evidence_level：深圳市机器人协会 / 2017 / 小天智能人形机器人 / L1-L2。

### 商用服务机器人线

2019 年铅笔道报道中的“大扫/小扫”分别对应户外清扫机器人和室内清扫机器人，强调自主规划、智能清扫、实时监控、APP 管理和大数据，可用于园区、校园、景区、室外广场和机场大厅等半封闭环境。[S10] 投资界报道进一步把产品聚焦到室内扫吸一体机器人和户外大型清扫机器人，强调低速无人驾驶、机器人技术、智慧环卫技术、云平台整合和多传感器融合。[S3]

这条产品线具备“物理环境中的感知、导航、任务执行”属性，因此可以宽泛归入服务机器人或狭义具身机器人边缘观察。但它缺少当前人形本体/具身大模型公司常见的关键证据：遥操作数据闭环、VLA/世界模型、灵巧操作、复杂双臂任务、开放开发者平台、量产本体参数、BOM/关节/灵巧手自研、客户侧 ROI 数据。

source/date/entity/evidence_level：铅笔道 / 2019-12-25 / 大扫、小扫 / L2-L3；投资界 / 2019-12-25 / 女娲室内扫吸一体机器人、户外大型清扫机器人 / L2。

### Nuwax Agent OS 线

Nuwax 的技术路线完全不同。它是智能体 OS，强调工作流、智能体构建、GUI/文本/语音/视觉交互、工具调用、记忆与自动化。官网写到 Nuwax 的能力可以迁移到实体机器人、桌面机器人、人形机器人和机器狗等载体，第二空间官网也列出“具身智能产品合作研发”案例入口。[S5][S6][S7]

它可以进入“具身 OS / Agent OS / 具身大脑观察池”，但不能作为深圳女娲机器人本体能力的证据。

source/date/entity/evidence_level：Nuwax 官网 / 2026-05-18 / Nuwax Agent OS / L1；西南财经大学 NLP 团队 / 2026-01-06 / Nuwax / L1；第二空间官网 / 2026-05-18 / 成都第二空间 / L1。

## 横向分析

### 与人形本体公司相比：不在同一竞争切面

如果把女娲机器人放进宇树、智元、乐聚、星动纪元、银河通用、傅利叶、优必选这类人形本体/通用机器人公司横向对比，它会立刻暴露口径问题。

这些公司至少有一个或多个当前可验证要素：全尺寸或准全尺寸机器人本体、持续新品发布、运动控制视频、量产价格或交付口径、具身模型/数据闭环、产业客户或展会验证、近期融资或上市公司文件。深圳女娲机器人本轮能核到的最新强证据主要停留在 2019 年清洁服务机器人和 Pre-A 融资。

因此，女娲机器人不应按“人形本体”参与横向比较。

### 与商用清洁机器人相比：早期进入者，但后续声量弱

更合理的比较对象是商用清洁服务机器人公司，例如高仙机器人、坎德拉、禧涤智能、艾可机器人，以及做配送/商服场景扩展的普渡、擎朗等。这个赛道的核心不是“像不像人”，而是导航、覆盖率、续航、补能、维护成本、清洁效果、客户 ROI、渠道和售后。

女娲机器人在 2019 年的定位其实不差：机场、公园、学校、园区、广场这些场景都符合清洁机器人商业化方向。问题在于后续没有形成公开可见的持续融资、客户侧采购、产品迭代和渠道网络。相比之下，头部清洁机器人公司在 2020 年后通常会持续披露大额融资、海外市场、物业/商业地产客户、产品矩阵和服务网络。女娲机器人缺的是这段“从样板场景到规模渠道”的中间证据。

### 与 Nuwax Agent OS 相比：一个是历史服务机器人，一个是智能体 OS

Nuwax 更接近具身智能软件层：智能体 OS、工作流、工具调用、多模态交互、跨硬件迁移。它的想象空间比深圳女娲机器人的历史清洁机器人更贴近 2026 年的 Agent/具身软件叙事。但 Nuwax 的硬件落地同样需要核验：官网和第二空间案例页能说明其有“具身智能产品合作研发”方向，不能直接证明已有规模化机器人部署、客户订单或硬件生态主导权。

因此正确做法不是把二者合并，而是拆成两个观察项：深圳女娲机器人归入“历史服务机器人/活跃度待核验”；Nuwax 另列“具身 OS/Agent OS 观察项”。

## 横纵交汇洞察

女娲机器人这个案例的价值，恰恰在于它提醒名单维护者：2016-2019 年的“机器人”与 2024-2026 年的“具身智能本体”不是同一个语义空间。

早年服务机器人公司的关键词是 Android、语音、视频、家庭陪伴、导览、清扫、安防、教育。今天具身智能公司的关键词变成了 VLA、世界模型、遥操作数据、灵巧手、全身控制、多模态任务规划、工业泛化、Sim2Real、量产本体和数据闭环。两个时代之间不是没有关系，但不能因为旧材料里出现“人形机器人”四个字，就把公司放进当下的人形本体清单。

女娲机器人纵向看有一个清晰转折：从小型家庭人形交互终端转向商用清洁服务机器人。这个转折是理性的。家庭机器人太难，清洁机器人更靠近刚需。但横向看，清洁机器人赛道后来竞争强度快速提高，女娲机器人没有留下足够公开证据证明自己跑出了渠道、产品和客户壁垒。

最可能的现实剧本是：深圳女娲机器人曾是深圳服务机器人热潮中的早期项目，2019 年有融资和样板场景，但后续活跃度下降；它可以作为中国服务机器人早期样本保留，不适合作为当前一级市场具身智能本体标的。

最危险的误判剧本是：把深圳女娲机器人、台湾 NUWA Robotics 和成都第二空间 Nuwax 合并成一个“女娲机器人”，于是融资、产品、地域、团队、客户全部错配。这会直接污染实体关系图谱。

最乐观的跟踪剧本是：如果后续能确认深圳女娲机器人仍在运营、或 evarobot 清洁机器人仍有持续客户与收入，那么它可作为“商用清洁服务机器人观察池”保留；如果 Nuwax 未来披露机器人客户、硬件伙伴或具身部署案例，则应另开“成都第二空间 / Nuwax Agent OS”研究页。
