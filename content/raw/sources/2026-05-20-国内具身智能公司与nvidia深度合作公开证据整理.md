## 1. 判定标准

### 1.1 “深度合作”的判定口径

本文件不把“用了 NVIDIA GPU / Jetson / 显卡”自动视为深度合作。至少需要满足以下条件之一：

1. **NVIDIA 官方明确点名**该公司/产品，并说明使用了 Isaac、GR00T、Cosmos、Omniverse、Jetson Thor/AGX 等核心机器人平台；
2. 公司进入 **NVIDIA Humanoid Robot Developer Program** 或类似早期接入/生态计划；
3. 有 NVIDIA Developer / Newsroom / 官方博客发布的**技术案例**；
4. 存在“共同开发 / co-developed / 联合框架 / 联合数据管线”级别的公开表述；
5. 公司自身官方披露与 NVIDIA 合作，且能被 NVIDIA 官方或其他高可信来源交叉验证。

### 1.2 来源可信度分级

| 可信度 | 来源类型 | 使用规则 |
|---|---|---|
| **S 级** | NVIDIA 官方博客、NVIDIA Developer、NVIDIA Newsroom、NVIDIA 官方产品页 | 可作为主证据。 |
| **A 级** | 公司官网/官方公众号/官方新闻稿 | 可作为辅助证据，需尽量与 NVIDIA 官方源交叉验证。 |
| **B 级** | 权威媒体、行业报告、会议报道 | 可用于补充背景，不单独作为“深度合作”结论依据。 |
| **C 级** | 社交媒体、视频、非官方转述、GitHub 社区讨论 | 只作为线索，不作为核心证据。 |

### 1.3 合作深度评级

| 评级 | 含义 |
|---|---|
| **A+** | 不只是采用 NVIDIA 技术，而是进入共同开发、数据/仿真/模型训练工作流或基础设施层。 |
| **A** | 官方明确披露，且涉及 Isaac Sim / Isaac Lab / GR00T / Cosmos / Jetson Thor 等核心机器人技术栈。 |
| **A-** | 官方明确披露产品集成 NVIDIA 核心技术，但公开工程细节有限。 |
| **B** | 官方披露进入生态/开发者计划或采用平台，但缺少具体产品、技术管线、联合工程细节。 |
| **观察** | 有市场传闻或弱证据，但不满足本文件高置信标准。 |

## 5. 竞争调研视角的结构化判断

### 5.1 NVIDIA 合作的真实含义

NVIDIA 在具身智能上的核心价值不是单一芯片，而是一个从云到机器人的工具链：

```text
训练算力 / DGX / 云平台
        ↓
仿真与合成数据 / Omniverse / Isaac Sim / Cosmos
        ↓
机器人学习 / Isaac Lab / GR00T-Mimic / GR00T-Dreams
        ↓
基础模型 / Isaac GR00T N 系列
        ↓
端侧部署 / Jetson AGX Orin / Jetson AGX Thor
        ↓
真实机器人场景：运动、操作、仓储、制造、服务
```

因此，判断一家国内具身智能公司和 NVIDIA 的合作深度时，应关注：

1. 是否只是用了 **Jetson / GPU**；
2. 是否进入 **Isaac Sim / Isaac Lab** 的仿真训练链路；
3. 是否使用 **GR00T / Cosmos / GR00T-Dreams / GR00T-Mimic** 这类基础模型与数据生成管线；
