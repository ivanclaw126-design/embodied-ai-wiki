# 腾讯 Robotics X

> Sources: 腾讯 Robotics X 横纵分析报告, 2026-05-18
> Raw: [腾讯 Robotics X 横纵分析报告](../../raw/sources/2026-05-18-腾讯-roboticsx-横纵分析报告.md)

## Overview

腾讯 Robotics X / Tencent Robotics X Lab 应按“[腾讯](../institutions/腾讯.md)内部企业级机器人实验室 + Tairos 具身智能开放平台 + 产业巨头关系节点”处理，而不是独立一级市场机器人公司。公开证据支持它覆盖移动本体、轮腿、灵巧操作、触觉、仿真、具身基础模型和 Tairos 平台，但截至 2026-05-18 未见独立工商主体、独立股权融资或对外销售整机本体产品线的强证据。

本页放在公司跟踪层，是为了兼容本库“公司页/观察池”查询入口；正文明确降级为产业巨头内部项目，不纳入独立本体公司主榜或融资排名。
