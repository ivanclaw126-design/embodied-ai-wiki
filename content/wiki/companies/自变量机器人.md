# 自变量机器人

> Sources: 自变量机器人横纵分析报告, 2026-05-18; 知乎专栏清华系盘点, 2025-03-23
> Raw: [自变量机器人横纵分析报告](../../raw/sources/2026-05-18-自变量机器人-横纵分析报告.md); [知乎清华系盘点](../../raw/sources/2025-03-23-盘点一些国内清华系的具身智能创业公司.md)

## Overview

自变量机器人是国内“具身基础模型 + 自研轮式双臂/轮式仿人形本体 + 真实场景数据闭环”路线的高融资密度公司。当前采用双主体穿透口径：自变量机器人科技（济南）有限公司作为工商/融资股东锚点，自变量机器人科技（深圳）有限公司 / X Square Robot 作为官网、品牌、产品和运营口径；两者暂按同一品牌体系处理，但不强行合并法律责任。

它已经从早期“具身智能通用大模型”种子线索升级为重点跟踪公司：公开产品包括 Quanta X1、Quanta X2、五指灵巧手 ArtiXon Hand 和 WALL-A/WALL-OSS/WALL-AS/WALL-B 模型路线；清华电子系和计算机系专项合作、58 到家家庭服务试点、工信部/民政部养老试点和小米/美团/阿里/字节/上汽等资本网络构成主要看点。当前仍不把它写成成熟量产本体公司，因为出货、收入、真实任务成功率、远程协助比例和客户复购均未公开闭合。

## 主体与团队

- 工商/融资锚点：自变量机器人科技（济南）有限公司，报道显示 2023-12 成立，法定代表人为王潜，2026-02 新增阿里云、国开雄安等股东。
- 品牌/运营口径：自变量机器人科技（深圳）有限公司 / X Square Robot，官网、产品页、融资报道和 WRC 展商页多使用深圳主体或深圳地址。
- 创始人/CEO：王潜，清华本硕、USC 机器人学习/家庭服务机器人研究经历，以及端到端模型/量化方法迁移是公司方法论来源。
- 联合创始人/CTO：王昊，出现在清华电子系专项启动会公开材料中。

## 场景与商业化

- 家庭保洁/家政：与 58 到家在深圳推出机器人保洁员上门服务，人机协作流程明确，是最强真实场景线索；但平台规模不等于自变量订单规模。
- WALL-B 入户计划：2026-04 发布会称 2026-05-25 左右新一代机器人首批入驻真实家庭；截至报告导入日仍是计划/招募口径，需后验数据。
- 养老/生活照料：自变量深圳牵头工信部/民政部智能养老服务机器人试点，招商观颐养老和深圳技术大学参与。
- 科研教育、商业清洁、酒店、物流分拣、工业组装和线束整理均有官网或展商页任务线索，客户订单和收入待证。
