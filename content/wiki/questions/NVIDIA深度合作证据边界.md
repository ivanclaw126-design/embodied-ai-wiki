# NVIDIA 深度合作证据边界

> Sources: 国内具身智能公司与 NVIDIA 深度合作公开证据整理, 2026-05-20
> Raw: [国内具身智能公司与 NVIDIA 深度合作公开证据整理](../../raw/sources/2026-05-20-国内具身智能公司与nvidia深度合作公开证据整理.md)

## 问题

在国内具身智能公司研究中，哪些公开材料足以支持“与 NVIDIA 深度合作”，哪些只能写成平台采用、生态进入、展示曝光或普通硬件使用？

## 当前采用口径

| 证据形态 | 当前处理 |
|---|---|
| NVIDIA 官方 Developer / Newsroom / 官方博客点名，并说明 Isaac、GR00T、Cosmos、Jetson Thor/AGX 等核心技术使用 | 可写入高置信关系表，仍需保留商业边界。 |
| 共同开发框架、benchmark、数据/仿真/评测基础设施 | 可评为 A+，但需区分基础设施公司与本体公司。 |
| 进入 Humanoid Robot Developer Program 或 Isaac Lab 生态协作者名单 | 可写为生态进入或早期接入，不自动写成产品级深度合作。 |
| 公司自身称使用 NVIDIA GPU/Jetson 或参加展会 | 只写硬件/展示/生态适配线索，缺 NVIDIA 侧一手材料时不升级。 |
| 市场传闻、社媒、非官方转述 | 只作为线索，不进高置信主表。 |

## 后续跟踪

- 优先检索 NVIDIA 官方博客、Developer、Newsroom、Isaac 产品页和 GTC/WRC 官方资料。
- 若出现客户侧采购、联合方案、开源仓库、benchmark 或模型训练案例，应回写 [国内具身智能公司 NVIDIA 合作关系](../relationships/国内具身智能公司NVIDIA合作关系.md) 和 [巨头与具身智能公司关系](../relationships/巨头与具身智能公司关系.md)。
- 如来源之间出现“公司自称深度合作”但 NVIDIA 未确认的冲突，应回写本页并在公司页“冲突与不确定性”中注明。
