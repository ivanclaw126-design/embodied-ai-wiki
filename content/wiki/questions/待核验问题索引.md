# 待核验问题索引

本页是开放问题的长期入口。后续导入新文档时，优先按问题类型写入对应页面，而不是继续创建“第几批/新导入”式页面。

| 问题类型 | 维护页面 | 写入规则 |
|---|---|---|
| 融资、估值、轮次、IPO、股权主体和累计融资口径 | [融资估值与口径冲突](融资估值与口径冲突.md) | 只要涉及金额、估值、融资轮次、老股/新股、上市融资边界或主体穿透，就写入本页。 |
| 公司级综合待核验事项 | [公司级待核验问题总表](公司级待核验问题总表.md) | 每家公司保留一行高风险未确认事项，避免散落在批次页。 |
| 客户、订单、收入确认、交付验收和复购 | [关系图谱待核验问题](关系图谱待核验问题.md) | 客户/合作/订单相关问题统一归入关系图谱待核验，再由客户合作关系页保存结构化记录。 |
| 高校、实验室、产业资本、供应链、人才流动和派系归因 | [关系图谱待核验问题](关系图谱待核验问题.md) | 关系强度、合作边界和人才来源不确定时写入本页，并同步检查 `relationships/` 与 `lineages/`。 |

## 维护规则

- 判断“已更新”只能看正文表格或正文段落是否吸收新信息，不能只看 Sources/Raw 或 index 摘要。
- 冲突信息保留来源差异，不强行平均为共识。
- 证据等级、source/date/entity/evidence_level 能写则写；未确认事项必须明确保留。
